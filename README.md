# pennant143-data

ペナント143（プロ野球監督シミュレーター）の選手データ。アプリは起動時に `players.json` を読み込み、「はじめから」で始めたときに反映します。

- `players.json` … 12球団（巨人, 阪神, DeNA, 広島, ヤクルト, 中日, ソフトバンク, 日本ハム, ロッテ, 楽天, オリックス, 西武の順）の野手 `B` と投手 `P`。
  - 野手: `[名前, 背番号, 主守備, 副守備, 投, 打, 生年月日, 育成, 外国人, ドラフト, ミート, パワー, バットコントロール, 走力, 肩力, 守備力, 捕球, 弾道, [特殊能力], 年俸(万円)]`
  - 投手: `[名前, 背番号, 投, 打, 生年月日, 育成, 外国人, ドラフト, 役割, 最速, コントロール, スタミナ, 球威, [[球種, 変化量, 割合%, 精度]...], [特殊能力], 年俸, ストレート割合%, ストレート平均球速]`
- 能力値・特殊能力は成績や評判からの推定です。
