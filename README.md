# pennant143-data

ペナント143（プロ野球監督シミュレーター）の選手データ。アプリは起動時に `players.json` を読み込み、「はじめから」で始めたときに反映します。

- `players.json` … 12球団（巨人, 阪神, DeNA, 広島, ヤクルト, 中日, ソフトバンク, 日本ハム, ロッテ, 楽天, オリックス, 西武の順）の野手 `B` と投手 `P`。
  - 野手: `[名前, 背番号, 主守備, 副守備, 投, 打, 生年月日, 育成, 外国人, ドラフト, ミート, パワー, バットコントロール, 走力, 肩力, 守備力, 捕球, 弾道, [特殊能力], 年俸(万円), 2026年までのNPB通算成績{G,PA,AB,H,HR,RBI,SB,...}]`
  - 投手: `[名前, 背番号, 投, 打, 生年月日, 育成, 外国人, ドラフト, 役割, 最速, コントロール, スタミナ, 球威, [[球種, 変化量, 割合%, 精度]...], [特殊能力], 年俸, ストレート割合%, ストレート平均球速, 2026年までのNPB通算成績{G,W,L,SV,HLD,K,out(アウト数),...}]`
- 能力値・特殊能力は成績や評判からの推定です。

## config.json（調整値）
数値を書き換えて push すると、アプリの次回起動時に反映されます。
- `tune` … 試合エンジンの調整値（コンタクト率・ファウル率・打球速度・守備範囲など。`tune_help` に主な項目の説明）
- `phys` … 打球の物理（空気抵抗 `cd`、揚力 `cl0`/`clk` など）
- `sae` … 特殊能力ごとの効果量（`sae_help` にどの特殊能力の値か）
- `lift` / `radj` / `rmid` / `rk` … 実在選手データをゲーム内の能力値に変換する補正（次に「はじめから」始めたときに反映）
